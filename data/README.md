## 열 설명 (`nopo_stores.csv`)
| 열 | 설명 |
|---|---|

| aliases | 영수증·간판 글자와 맞춰 볼 별칭 (`|` 구분): 목록과 상세의 이름 차이, `(주)`·`주식회사`·괄호를 뺀 이름 |
| programs | `BAEKNYEON`, `ORAE`, 둘 다면 `BAEKNYEON|ORAE` |
| category_raw / category_group / is_food | 업종 원문 / 묶음 / 음식점 여부(지도 기본 필터) |
| sido, sigungu, address, phone | 지역, 주소, 전화(숫자만) |
| founded_date | 소상공인마당 상세의 창업일 원문 |
| founded_year / founded_source | 앱이 쓰는 창업연도와 출처: `SBIZ_DETAIL`(상세 창업일), `INTRO_TEXT`(소개글의 연도), `INTRO_TEXT_EARLIER`(상세 창업일보다 이른 소개글 연도), `INTRO_YEARS`(소개글의 “50년 넘게” 같은 업력으로 올해 기준 역산, 보수적), `SEOUL_RELEASE`(서울시 발표) |
| years_now | 올해 기준 업력 (앱은 최소 30으로 계산) |
| generation | n대째 (소개에 적힌 경우) |
| menu_items | 소개에 이름이 나온 대표 메뉴·상품 (`|` 구분) |
| hours, amenities, homepage, sns | 영업시간, 이용정보, 홈페이지 |

## 수집 방법과 한계
- 백년가게: 소상공인마당 목록 72쪽 전체와 가게별 상세 페이지 1,139곳을 웹 읽기 도구로 수집. 요청을 나눠 보내 사이트 부담을 줄임.
- 오래가게: 공식 누리집에 접속되지 않아 서울시 보도자료·미디어허브의 선정 발표를 회차별로 모아 정리. 발표에 없는 정보(주소·전화 등)는 비어 있을 수 있음.
- 영문 자료의 로마자 표기에서 한글 상호를 복원한 가게는 `NAME_UNVERIFIED`로 표시. 한글 기사로 상호·주소를 확인한 가게(예: 대구참기름집, 순희네반찬, 손맛김밥, 비원떡집)는 표시를 지우고 출처를 `source_url`에 남김. 보정한 가게는 `raw/orae_stores.jsonl`의 `name_fixed`·`verified` 칸에 근거가 남아 있음.
- 소개글은 원문을 그대로 옮기지 않고 짧게 요약된 문장. 출시 전에는 다시 쓰거나 출처를 표시할 것.
- 소상공인마당의 창업일은 현재 사업자 기준일 수 있어, 소개글에 더 이른 창업연도(“1965년에 문을 연”, “1970년 … 출발” 등)가 있으면 그 연도를 사용. “1960년대”처럼 연대만 있으면 그 연대의 첫 해.
- 전화번호가 여러 개면 첫 번호만, 0으로 시작하지 않는 등 형식이 틀린 번호는 비움. 같은 가게가 두 번 지정된 경우는 `DUPLICATE` 표시 후 앱에서 하나만 사용.
- 창업연도가 없는 가게는 앱에서 업력 30년(공식 지정 최소 기준)으로 계산.
- 좌표는 API 키가 필요해 비어 있음: `python tools/geocode.py --provider naver` (또는 `kakao`) → `python tools/build_catalog.py`. 주소가 없는 오래가게는 `--provider kakao`의 이름 검색(시도·자치구 + 가게 이름)으로 찾고, 찾은 주소를 채운 뒤 `COORD_FROM_NAME`을 붙임 → 지도에서 위치를 확인할 것.
- 상세가 비어 있는 가게는 컴퓨터에서 `python tools/crawl_baeknyeon.py --only-missing`으로 보충 (이 도구의 정규식은 실제 페이지로 시험하지 못했으니 첫 실행 뒤 `data/raw/bn_detail_local.jsonl` 5줄을 눈으로 확인).
- 소상공인마당 목록은 소개 페이지가 있는 가게만 보여 준다. 공식 지정리스트 CSV(공공데이터포털, 1,511행)를 내려받아 `python tools/import_official_list.py --csv 파일.csv` → `python tools/build_catalog.py`를 실행하면 빠진 가게가 `OFFICIAL_ONLY`로 더해짐(이름·주소·전화만, 창업연도 미상 → 앱은 업력 30년).
- 전화번호 중 0507 같은 가상번호(가게 대표 번호가 아닌 경우)는 영수증 번호와 다를 수 있다. 앱은 전화 또는 상호 중 하나만 맞으면 통과시킨다.
