# 노포 천년 미식가 — Figma 토큰 ➔ Compose (`Color.kt`, `Theme.kt`, `Dimens.kt`) 자동 동기화 Gradle 태스크 가이드 (v0.4)

> **프로젝트**: 노포 천년 미식가 (Nopo-Cheonnyeon Gourmet Passport)  
> **목적**: `figma/nopo-tokens.json` (또는 Figma Variables 내보내기 JSON)이 수정되거나 CI/CD 파이프라인이 구동될 때마다 **별도의 수동 복사 작업 없이** 안드로이드 프로젝트 내의 `Color.kt`, `Theme.kt`, `Dimens.kt` 코드를 자동 생성·동기화하는 **독립형 Gradle 커스텀 태스크 (`syncDesignTokens`)** 구축  
> **버전**: v0.4 Production Release Architecture

---

## 1. 아키텍처 개요 및 동작 흐름 (Data Flow)

외부 서드파티 npm 패키지나 무거운 플러그인 설치 없이, 순수 **Gradle Kotlin DSL (`build.gradle.kts`)**과 경량 JSON 파서를 활용하여 프로젝트 빌드 시 항상 단일 진실 공급원(SSOT)을 유지합니다.

```
[figma/nopo-tokens.json] (디자인 토큰 마스터)
            │
            ▼  (./gradlew syncDesignTokens 또는 ./gradlew preBuild 시 자동 실행)
[Custom Gradle Task: SyncDesignTokensTask]
            │
            ├──▶ app/src/main/java/com/nopo/cheonnyeon/core/designsystem/theme/Color.kt
            ├──▶ app/src/main/java/com/nopo/cheonnyeon/core/designsystem/theme/Theme.kt
            └──▶ app/src/main/java/com/nopo/cheonnyeon/core/designsystem/theme/Dimens.kt
```

## 2. Gradle 커스텀 태스크 전체 소스코드 (`app/build.gradle.kts` 또는 `buildSrc`)

`app/build.gradle.kts` 하단에 아래 스크립트를 추가하면 `./gradlew syncDesignTokens` 명령어로 토큰 파일을 파싱하여 코드를 100% 자동 생성합니다.

```kotlin
import groovy.json.JsonSlurper
import java.io.File

// =============================================================================
// [Gradle Task] Figma Tokens JSON -> Jetpack Compose Theme Auto-Generator
// =============================================================================

tasks.register("syncDesignTokens") {
    group = "design-system"
    description = "Parses figma/nopo-tokens.json and auto-generates Color.kt, Theme.kt, and Dimens.kt for Jetpack Compose"

    val tokensFile = rootProject.file("figma/nopo-tokens.json")
    val outputDir = file("src/main/java/com/nopo/cheonnyeon/core/designsystem/theme")

    inputs.file(tokensFile)
    outputs.dir(outputDir)

    doLast {
        if (!tokensFile.exists()) {
            logger.warn("⚠️ Warning: figma/nopo-tokens.json not found at: ${tokensFile.absolutePath}")
            return@doLast
        }

        outputDir.mkdirs()

        // 1. JSON 파일 파싱 (Groovy JsonSlurper)
        val json = JsonSlurper().parse(tokensFile) as Map<String, Any>
        val collections = json["collections"] as? List<Map<String, Any>> ?: emptyList()

        val colorCollection = collections.find { it["name"] == "Color" }
        val dimensCollection = collections.find { it["name"] == "Dimensions & Spacing" }

        // =====================================================================
        // 2. Color.kt 코드 생성
        // =====================================================================
        val colorSb = StringBuilder()
        colorSb.append("""
            package com.nopo.cheonnyeon.core.designsystem.theme

            import androidx.compose.ui.graphics.Color

            /**
             * [AUTO-GENERATED by Gradle Task :syncDesignTokens]
             * Do not edit directly. Modify figma/nopo-tokens.json instead.
             */

        """.trimIndent())

        val lightColors = mutableMapOf<String, String>()
        val darkColors = mutableMapOf<String, String>()

        if (colorCollection != null) {
            val variables = colorCollection["variables"] as? List<Map<String, Any>> ?: emptyList()
            
            colorSb.append("// --- Light Theme Tokens ---\n")
            for (v in variables) {
                val rawName = v["name"] as String // e.g. color/sign
                val desc = v["description"] as? String ?: ""
                val values = v["valuesByMode"] as? Map<String, String> ?: emptyMap()

                val lightHex = values["mode-light"] ?: values["Light"] ?: "#000000"
                val darkHex = values["mode-dark"] ?: values["Dark"] ?: "#FFFFFF"

                val valName = toCamelCase(rawName.removePrefix("color/"))

                lightColors[valName] = formatColorHex(lightHex)
                darkColors[valName] = formatColorHex(darkHex)

                if (desc.isNotEmpty()) colorSb.append("// $desc\n")
                colorSb.append("val Nopo${valName}Light = Color(${formatColorHex(lightHex)})\n")
            }

            colorSb.append("\n// --- Dark Theme Tokens (WCAG 4.5:1+ Compliant) ---\n")
            for (v in variables) {
                val rawName = v["name"] as String
                val values = v["valuesByMode"] as? Map<String, String> ?: emptyMap()
                val darkHex = values["mode-dark"] ?: values["Dark"] ?: "#FFFFFF"
                val valName = toCamelCase(rawName.removePrefix("color/"))

                colorSb.append("val Nopo${valName}Dark = Color(${formatColorHex(darkHex)})\n")
            }
        }

        val colorFile = File(outputDir, "Color.kt")
        colorFile.writeText(colorSb.toString())
        println("✅ Successfully generated: ${colorFile.absolutePath}")

        // =====================================================================
        // 3. Theme.kt 코드 생성 (Material 3 DarkColorScheme / LightColorScheme)
        // =====================================================================
        val themeSb = StringBuilder()
        themeSb.append("""
            package com.nopo.cheonnyeon.core.designsystem.theme

            import androidx.compose.foundation.isSystemInDarkTheme
            import androidx.compose.material3.MaterialTheme
            import androidx.compose.material3.darkColorScheme
            import androidx.compose.material3.lightColorScheme
            import androidx.compose.runtime.Composable

            /**
             * [AUTO-GENERATED by Gradle Task :syncDesignTokens]
             * Do not edit directly. Modify figma/nopo-tokens.json instead.
             */

            private val DarkColorScheme = darkColorScheme(
                primary = NopoPrimaryDark,
                onPrimary = NopoSignDark,
                surface = NopoSurfaceDark,
                onSurface = NopoInkDark,
                background = NopoPaperDark,
                onBackground = NopoInkDark,
                outline = NopoLineDark,
                error = NopoStampDark,
                secondary = NopoBrassDark,
                onSecondary = NopoSignDark
            )

            private val LightColorScheme = lightColorScheme(
                primary = NopoPrimaryLight,
                onPrimary = NopoSurfaceLight,
                surface = NopoSurfaceLight,
                onSurface = NopoInkLight,
                background = NopoPaperLight,
                onBackground = NopoInkLight,
                outline = NopoLineLight,
                error = NopoStampLight,
                secondary = NopoBrassLight,
                onSecondary = NopoPaperLight
            )

            @Composable
            fun NopoTheme(
                darkTheme: Boolean = isSystemInDarkTheme(),
                content: @Composable () -> Unit
            ) {
                val colorScheme = if (darkTheme) DarkColorScheme else LightColorScheme
                MaterialTheme(
                    colorScheme = colorScheme,
                    content = content
                )
            }

        """.trimIndent())

        val themeFile = File(outputDir, "Theme.kt")
        themeFile.writeText(themeSb.toString())
        println("✅ Successfully generated: ${themeFile.absolutePath}")

        // =====================================================================
        // 4. Dimens.kt 코드 생성 (수치 및 8dp 그리드)
        // =====================================================================
        if (dimensCollection != null) {
            val dimensSb = StringBuilder()
            dimensSb.append("""
                package com.nopo.cheonnyeon.core.designsystem.theme

                import androidx.compose.ui.unit.dp

                /**
                 * [AUTO-GENERATED by Gradle Task :syncDesignTokens]
                 * Dimensions & 8dp Grid Spacing Tokens
                 */
                object NopoDimens {

            """.trimIndent())

            val variables = dimensCollection["variables"] as? List<Map<String, Any>> ?: emptyList()
            for (v in variables) {
                val rawName = v["name"] as String // e.g. spacing/md, radius/card
                val values = v["valuesByMode"] as? Map<String, Any> ?: emptyMap()
                val num = values.values.firstOrNull() ?: 0

                val valName = toCamelCase(rawName.replace('/', '_'))
                dimensSb.append("    val $valName = ${num}.dp\n")
            }
            dimensSb.append("}\n")

            val dimensFile = File(outputDir, "Dimens.kt")
            dimensFile.writeText(dimensSb.toString())
            println("✅ Successfully generated: ${dimensFile.absolutePath}")
        }
    }
}

// --- 헬퍼 함수: 카멜케이스 변환 및 Hex 포맷 ---
fun toCamelCase(input: String): String {
    return input.split("-", "_", " ")
        .filter { it.isNotEmpty() }
        .joinToString("") { it.capitalize() }
}

fun formatColorHex(hex: String): String {
    val clean = hex.removePrefix("#")
    return if (clean.length == 6) {
        "0xFF$clean"
    } else if (clean.length == 8) {
        "0x$clean"
    } else {
        "0xFF000000"
    }
}
```

## 3. 앱 컴파일 시 자동 동기화 훅(Hook) 연결

매번 터미널에서 태스크를 수동으로 실행하지 않고, **Android Studio에서 `Run` (재생 버튼)을 누르거나 `./gradlew assembleDebug` 빌드 시 자동으로 최신 토큰을 동기화**하도록 `preBuild` 의존성을 연결합니다.

`app/build.gradle.kts`의 가장 하단에 다음 1줄을 추가합니다:

```kotlin
// 안드로이드 사전 빌드(preBuild) 단계에서 토큰 동기화 태스크 자동 선행 실행
tasks.named("preBuild") {
    dependsOn("syncDesignTokens")
}
```

## 4. 터미널 및 Android Studio 실행 방법

### 4.1 터미널 CLI 단독 실행
```bash
# 디자인 토큰 즉시 동기화 실행
./gradlew syncDesignTokens

# Windows PowerShell의 경우
.\gradlew syncDesignTokens
```

**실행 출력 결과:**

### 4.2 Android Studio GUI 메뉴에서 실행
1. 우측 사이드바의 **`Gradle`** 패널 열기.
2. `NopoCheonnyeon` ➔ `app` ➔ `Tasks` ➔ **`design-system`** 폴더 확장.
3. **`syncDesignTokens`**를 더블 클릭하여 실행.

```kotlin
// --- Light Theme Tokens ---
```

## 6. GitHub Actions CI/CD 파이프라인 연동 (`android-ci.yml`)

GitHub에 코드를 푸시할 때 토큰 파일이 변경되었더라도 CI 파이프라인에서 자동으로 최신 코드로 컴파일 및 단위 테스트를 통과하도록 보장합니다.

`.github/workflows/android-ci.yml`의 빌드 단계에 다음 단계를 추가합니다:

```yaml
- name: 🎨 Sync Figma Design Tokens
  run: ./gradlew syncDesignTokens

- name: 🧪 Run Domain Unit Tests
  run: ./gradlew testDebugUnitTest --stacktrace
```
