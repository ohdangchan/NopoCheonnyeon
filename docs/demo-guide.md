# 시연 가이드 (해커톤, 공기계 설치)

## 1. 공기계에 설치
1. 공기계에서 **개발자 옵션 > USB 디버깅**을 켜고 PC에 연결(허용 팝업에서 "허용").
2. PC 터미널(프로젝트 폴더): `.\gradlew.bat assembleRelease`
3. 설치: `adb install -r app\build\outputs\apk\release\app-release.apk`
   - adb 경로: `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`
   - 이전에 디버그 앱이 있으면 먼저 `adb uninstall com.nopo.cheonnyeon` (서명이 달라 덮어쓰기 불가).
   - 폰에 파일로 옮겨 설치할 때는 APK를 폰으로 복사 → 파일 앱에서 열기 → "출처를 알 수 없는 앱 설치" 허용.
4. 첫 실행에서 허용할 것: 위치(정확한 위치), 카메라, (알림은 쓰지 않음). 기기 위치(GPS)도 켜기.
5. 인터넷(Wi-Fi/데이터)이 필요함: 로그인·리뷰·사진은 온라인. 가게 목록은 앱에 들어 있어 오프라인에서도 보임.

## 2. 시연용 계정
- 시연 직전에 앱에서 직접 가입하세요(이메일 형식이면 아무 값, 비밀번호 영문+숫자 8자 이상, 닉네임 2~12자).
- 시험 계정은 설정 > 회원 탈퇴로 삭제할 수 있음.

## 3. 시연 시나리오 (5분)
1. **온보딩 → 가입**: 3장 소개 → 회원가입 → 지도가 바로 열림.
2. **지도 탐색**: 필터 칩(음식점만/백년가게/오래가게/안 가 본 곳) → 검색창에 "설렁탕" → 목록(가까운 순/업력 순) → 지도로 돌아와 마커 탭 → 하단 시트(업력·배지·보상).
3. **노포 상세**: 큰 업력("111년"), 배지, 보상 박스("방문 인증하면 세월 +111년 · 다음 칭호까지 189년"), 영업시간·메뉴·길찾기.
4. **방문 인증** (심사위원 앞에서 실제 인증을 보이려면 테스트 가게 사용):
   - 설정 > 앱 정보를 5번 탭 > "테스트 가게 만들기(현재 위치)".
   - 지도 탐색 > 목록 > 맨 위 "노포천년테스트식당(0m)" > 방문 인증하기.
   - 영수증: `tools\test-images\test_receipt_live.html`을 다른 화면(노트북)에 띄우고 촬영 → 도장.
   - 또는 "영수증이 없어요" → 내 위치 확인 → 간판 사진 → (글자 인식이 안 되면 3번 뒤 "위치 확인 도장").
5. **도장 연출**: 380ms 찍힘·세월 숫자 올라감·진동 → 내 패스포트에서 게이지·칭호·도장 격자·도장 상세.
6. **리뷰** (실제 가게 인증 기록이 서버에 있어야 함): 방문 후 상세 > 평점 남기기 → 평균 평점·리뷰 목록 → 닉네임 탭 → 유저 프로필.
7. **복원**: 앱 삭제 후 다시 설치·로그인하면 세월·도장이 돌아옴.

## 3-1. 새로 들어간 볼거리 (2026-10-20)
- **재방문율:** 가게 상세의 평점 영역에 "재방문 K명 / 방문 N명"(방문자 5명 이상이면 퍼센트). 같은 사용자가 다른 날 다시 인증하면 K가 올라간다.
- **칭호 승급 연출:** 세월 경계(100·300·600·1,000년)를 넘는 인증 직후 팝업. 시연 때는 설정 > 앱 정보 5번 탭 > "가상 방문 기록"(디버그 빌드)으로 세월을 빠르게 쌓을 수 있다.
- **도장 결과 화면:** 인증 전 → 후 세월, 천 년 게이지, 현재 칭호.
- **방문 기록 공개 범위:** 설정 > 방문 기록 공개 범위(전체 / 횟수만 / 나만 보기). 다른 계정으로 프로필을 열어 보여 준다.
- **프로필:** 가입일, 게이지, 다녀온 노포(등급 도장·첫 방문일·단골 횟수), 매긴 평점 탭.
- **영수증 가이드 틀**, **가게 정보 오류 제보**, **서버 기록 복원 배너**(로그인 직후), **기기 시계 오차 경고**(10분 넘게 어긋날 때).
- 시연 전에 `docs/nopo-09-real-device-qa.md` 13장 ★ 항목을 한 번씩 해 보고, 실패하면 시연에서 뺀다.

## 4. 시연 중 문제 대처
| 증상 | 조치 |
|---|---|
| 지도가 비어 있음 | 인터넷 확인. 오류 배너에 코드가 나오면 네이버 콘솔의 패키지명(`com.nopo.cheonnyeon`) 확인 |
| "위치를 찾지 못했어요" | 기기 위치 켜기, 정확한 위치 허용, 하늘이 보이는 곳 |
| 영수증이 인식 안 됨 | 밝게, 평평하게, 가게명·전화·날짜가 한 화면에 보이게. 실패하면 "가게 사진으로 인증" |
| 사진이 안 뜸 | 인터넷 확인. 사진 없는 가게는 글자 카드가 정상 |
| 로그인 안 됨 | 이메일·비밀번호 재확인, 인터넷 확인 |

## 5. 데이터 수치 (발표용)
- 노포 1,277곳(백년가게 1,138 · 오래가게 139), 좌표 1,181곳(92.5%), 공식 사진 86곳.
- 도장 등급: 30~49년 청록 / 50~99년 붉은 / 100년 이상 금빛. 칭호(100년마다): 첫술 식객 → 골목 단골(100) → 국밥 순례자(200) → 시장통 어르신(300) → 가마솥 감별사(400) → 노포 길잡이(500) → 맛의 장인(600) → 세월 지킴이(700) → 미식 도인(800) → 전설의 식객(900) → 천년 미식가(1,000).
- 인증: 영수증(전화 일치 또는 상호 유사도 0.70 이상, 24시간 이내) / 가게 사진(30m 이내, 이름 유사도 0.60 이상 또는 전화) / 위치 확인.
- 개인정보: 위치 좌표와 영수증 내용은 서버에 저장하지 않음.

## 현재 위치 시연 가게 시나리오 (2026-10-20)
준비: 설정 앱 정보 5탭 > 개발자 도구 > "테스트 가게·기록 삭제" → "테스트 가게 만들기 (현재 위치)". PC에서 `python tools/gen_test_receipt.py`를 실행하고 `tools/test-images/demo_scenarios.html`을 모니터에 띄운다(버튼 ①~④로 그림 전환). 영수증은 만든 시각부터 24시간 안에만 유효하고, 같은 영수증은 한 번만 쓸 수 있다.

| 시나리오 | 방법 | 기대 결과 |
|---|---|---|
| 1. 인증 전에는 리뷰 불가 | 가게 상세 > 평점과 리뷰 | "방문 인증한 사람만 평점을 남길 수 있어요", 작성 버튼 없음 |
| 2. 영수증 바로 인증 | ① `test_receipt_today.png`를 앱 카메라로 촬영 | 도장 연출 → 가게 상세에서 리뷰 작성(이 기기에만 저장, 평균·개수에 합산) |
| 3. 영수증 실패 → 가게 사진 인증 | 흐릿하게/가려서 3번 실패 또는 "가게 사진으로 인증하기" → 위치 확인(30m) → ④ 간판 또는 메뉴판 촬영 | 도장(방법: 가게 사진) → 리뷰 작성. 글자 확인이 3번 실패해도 30m 안이면 "위치 확인 도장" 선택지(설정 스위치로 끌 수 있음) |
| 4-a. 24시간 지난 영수증 | ② `test_receipt_expired.png` 촬영 | "영수증이 24시간이 지났어요"(E_RECEIPT_EXPIRED) → 가게 사진 인증으로 이어가기 |
| 4-b. 다른 가게 영수증 | ③ `test_receipt_other.png` 촬영 | "영수증의 가게 이름이 달라요"(E_RECEIPT_MISMATCH) |
| 다시 처음부터 | "테스트 가게·기록 삭제" → 다시 만들기, 영수증 이미지 다시 생성 | 방문 기록·내 리뷰가 지워짐 |

> 시험용 가게의 도장·리뷰는 서버에 올라가지 않고 세월·하루 한도에도 들어가지 않는다. 리뷰에는 사진을 카메라·앨범에서 최대 3장 붙일 수 있고(2026-10-20 추가), 가게 사진 인증의 인증샷은 기기에만 보관되어 도장 상세에서 보인다.

## 2026-10-21 추가 시연 시나리오 (AI·연출)
공통: 처음 AI 기능을 쓸 때 "AI 분석 안내" 동의 대화상자가 한 번 뜬다(동의하면 이후 안 뜸). 인터넷 필요. 영수증 이미지는 `python tools/gen_test_receipt.py` 후 `tools/test-images/demo_scenarios.html`(탭 ①~⑦)을 모니터에 띄워 앱 카메라로 촬영.

| 시나리오 | 방법 | 기대 결과 |
|---|---|---|
| A. 스캔 연출(성공) | 시험용 가게 > 방문 인증 > ① `test_receipt_today.png` 촬영 | 찍은 영수증 위를 **빨간 레이저**가 위아래로 훑고 → 인식한 글자에 **형광펜**이 차례로 칠해짐 → 도장 쾅 → 폭죽 |
| B. AI 촬영 도우미(위쪽 잘림) | ⑤ `test_receipt_cut_top.png` 촬영 | 형광펜 연출 후 "영수증의 가게 이름이 달라요" + **AI 촬영 도우미** 팝업("가게 이름이 잘렸어요, 위쪽까지 찍어 주세요" 류). "다시 찍기" 누르면 카메라로 복귀 |
| C. AI 촬영 도우미(흐림/어두움) | ⑥ `test_receipt_blur.png`, ⑦ `test_receipt_dark.png` 촬영 | 글자를 못 읽었다는 안내 + AI가 초점·밝기 조언 |
| D. 한 번에 안 되는 경우 | B→"다시 찍기"→ ① 정상 영수증 | 정상 인증으로 이어짐 |
| E. AI 번역 | 가게 상세 > 소개글 아래 "AI 번역" > English/日本語/… 또는 "직접 입력"(예: Thai) | 소개글·한 줄 소개·리뷰가 선택한 언어로 바뀜, "원문 보기"로 복귀 |
| F. AI 노포 도우미 | 지도 탭 맨 위 "AI 노포 도우미" > 예시 칩 3개(말로 찾기·천년 경로·오늘의 코스) | 추천 가게 카드(눌러서 상세 이동). 앱을 닫았다 열어도 대화 기록이 남음, "기록 지우기"로 삭제 |
| G. AI 메뉴 룰렛·리뷰 분석 | 패스포트 > "AI 메뉴 룰렛"(다시 돌리기 최대 10번), 가게 상세 > "AI로 리뷰 분석하기" | 메뉴 3개씩(중복 없음) / 특장점·추천 메뉴·아쉬운 점 |

주의: 영수증 사진은 AI 촬영 도우미를 위해 **인식에 실패했을 때만** Gemini로 전송되고(동의 필요) 저장하지 않는다. 레이저·형광펜 연출 위치는 촬영 순간의 장면 기준이라 사진이 비스듬하면 약간 어긋날 수 있다.
