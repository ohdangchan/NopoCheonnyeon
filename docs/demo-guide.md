# 시연 가이드 (해커톤, 공기계 설치)

## 1. 공기계에 설치
1. 공기계에서 **개발자 옵션 > USB 디버깅**을 켜고 PC에 연결(허용 팝업에서 "허용").
2. PC 터미널(프로젝트 폴더): `.\gradlew.bat assembleRelease`
3. 설치: `adb install -r app\build\outputs\apk\release\app-release.apk`
   - adb 경로: `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`
   - 이전에 디버그 앱이 있으면 먼저 `adb uninstall com.nopo.cheonnyeon` (서명이 달라 덮어쓰기 불가).
   - 폰에 파일로 옮겨 설치할 때는 APK를 폰으로 복사 → 파일 앱에서 열기 → "출처를 알 수 없는 앱 설치" 허용.
4. 첫 실행에서 허용할 것: 위치(정확한 위치), 카메라, (알림은 쓰지 않음). 기기 위치(GPS)도 켜기.
5. 인터넷(Wi-Fi/데이터)이 필요함: 로그인·리뷰·사진은 온라인. 가게 목록은 앱에 들어 있어 오프라인에서도 보임.

## 2. 시연용 계정
- 시연 직전에 앱에서 직접 가입하세요(이메일 형식이면 아무 값, 비밀번호 영문+숫자 8자 이상, 닉네임 2~12자).
- 시험 계정은 설정 > 회원 탈퇴로 삭제할 수 있음.

## 3. 시연 준비 (시연 30분 전)
1. 최신 릴리스 APK 설치(위 1번). 위치·카메라 권한 허용, GPS 켜기, 인터넷 연결. 폰의 **자동 회전은 세로 고정** 권장.
2. 로그인(시연 계정) 후 **설정 앱 정보 5번 탭 > 개발자 도구**:
   - "시연용 패스포트 채우기(637년)" — 패스포트·명예의 전당·AI 룰렛에 쓸 데이터.
   - "테스트 가게·기록 삭제" → "**테스트 가게 만들기 (현재 위치)**" — `노포천년테스트식당`이 **지금 서 있는 자리**에 생긴다(위치 30m 시험용). 시연 장소에 도착한 뒤 만들 것. 장소를 옮기면 다시 만든다.
3. PC에서 `python tools/gen_test_receipt.py` 실행(영수증 시각을 새로 만듦, 지난 그림은 자동 삭제) → 브라우저로 `tools/test-images/demo_scenarios.html` 열기(모니터 가득, 왼쪽에서 시나리오 선택, ↑↓ 키로 이동, 영수증은 틀 안에 크게).
4. 처음 AI 기능을 쓸 때 "AI 분석 안내" 동의 창이 뜬다(한 번만). 시연 전에 미리 동의해 두면 매끄럽다.

## 3-1. 시연 시나리오 (모두 `demo_scenarios.html`에 단계·기대 결과·그림이 들어 있음)
영수증·가게 사진은 모두 **노포천년테스트식당** 기준. 시험용 가게의 도장·리뷰는 서버에 올라가지 않고 세월·하루 한도에 들어가지 않는다. 같은 영수증을 두 번 쓰는 중복 차단(E_RECEIPT_DUP)은 서버 판정이라 시험용 가게에서는 보이지 않으므로 시연하지 않는다. 시나리오를 다시 하려면 "테스트 가게·기록 삭제 → 다시 만들기".

| # | 시나리오 | 그림 | 핵심 확인 |
|---|---|---|---|
| 1 | 인증 전에는 리뷰 불가 | — | "방문 인증한 사람만 평점을 남길 수 있어요", 예시 리뷰·재방문율 33% |
| 2 | 영수증 바로 성공 | 정상 영수증 A | **빨간 레이저 훑기 → 형광펜 → 도장 쾅(진동) → 폭죽 → "평점·리뷰 남기기" → 리뷰 + 사진 3장** |
| 3 | 위쪽 잘림 → AI 촬영 도우미 → 다시 찍어 성공 | 위쪽 잘림 → 정상 영수증 B | 팝업 "가게 이름이 잘렸어요, 위쪽까지 찍어 주세요" 류 → "다시 찍기" |
| 4 | 흐림·어두움 → AI 촬영 도우미 | 흐린 / 어두운 영수증 | 원인별 안내(초점·밝기) |
| 5 | 다른 가게 / 24시간 지남 | 행복분식 영수증 / 50시간 전 영수증 | E_RECEIPT_MISMATCH(+AI 안내) / E_RECEIPT_EXPIRED |
| 6 | 영수증 없이 → 가게 사진 + 위치(30m) | 메뉴판·간판 | 거리 0m → 간판/메뉴판 촬영 → 도장. 3번 실패 시 "위치 확인 도장" |
| 7 | AI 번역 | — | 소개글·리뷰가 English/日本語/직접 입력 언어로, "원문 보기" |
| 8 | AI 노포 도우미(지도 맨 위) | — | 말로 찾기 · 천년 경로 · 오늘의 코스, 추천 카드 → 상세, 앱 재시작 후에도 대화 기록 |
| 9 | AI 메뉴 룰렛 · 리뷰 AI 분석 | — | 3개씩, 다시 돌리기 최대 10번(30개, 중복 없음) / 특장점·추천 메뉴·아쉬운 점 |
| 10 | 칭호 도감·승급 연출·공유 카드·명예의 전당 | — | 11단계 칭호, 폭죽 승급 연출, QR 공유 카드, 시연용 순위 |

권장 진행 순서(약 8분): 1 → 2 → 3 → 6 → 8 → 7 → 9 → 10 (4·5는 질문이 나오면). 영수증은 A·B·C 세 장이라 성공 시연을 세 번까지 할 수 있다.

주의: 영수증 사진은 **인식에 실패했을 때만** AI 촬영 도우미를 위해 Gemini로 전송되고(동의 필요) 저장하지 않는다. 레이저·형광펜 위치는 촬영 순간의 장면 기준이라 사진이 비스듬하면 약간 어긋날 수 있다.

## 4. 시연 중 문제 대처
| 증상 | 조치 |
|---|---|
| 지도가 비어 있음 | 인터넷 확인. 오류 배너에 코드가 나오면 네이버 콘솔의 패키지명(`com.nopo.cheonnyeon`) 확인 |
| "위치를 찾지 못했어요" | 기기 위치 켜기, 정확한 위치 허용, 하늘이 보이는 곳 |
| 영수증이 인식 안 됨 | 밝게, 평평하게, 가게명·전화·날짜가 한 화면에 보이게. 실패하면 "가게 사진으로 인증" |
| 사진이 안 뜸 | 인터넷 확인. 사진 없는 가게는 글자 카드가 정상 |
| 로그인 안 됨 | 이메일·비밀번호 재확인, 인터넷 확인 |

## 5. 데이터 수치 (발표용)
- 노포 1,277곳(백년가게 1,138 · 오래가게 139), 좌표 1,181곳(92.5%), 공식 사진 86곳.
- 도장 등급: 30~49년 청록 / 50~99년 붉은 / 100년 이상 금빛. 칭호(100년마다): 첫술 식객 → 골목 단골(100) → 국밥 순례자(200) → 시장통 어르신(300) → 가마솥 감별사(400) → 노포 길잡이(500) → 맛의 장인(600) → 세월 지킴이(700) → 미식 도인(800) → 전설의 식객(900) → 천년 미식가(1,000).
- 인증: 영수증(전화 일치 또는 상호 유사도 0.70 이상, 24시간 이내) / 가게 사진(30m 이내, 이름 유사도 0.60 이상 또는 전화) / 위치 확인.
- 개인정보: 위치 좌표와 영수증 내용은 서버에 저장하지 않음.
