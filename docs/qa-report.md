## 1-2. 릴리스 APK 실기기 확인 (발견·수정한 버그 포함)
- **발견**: 처음 릴리스 APK는 시작하자마자 종료됨(`IllegalAccessError: kotlin.text.j` — R8 최적화가 Crashlytics와 충돌). 디버그 빌드에서는 재현되지 않는 문제라 릴리스를 직접 설치해야만 잡을 수 있었다.
- **수정**: `app/src/main/keepRules/rules.keep`에 `-dontoptimize` 추가(축소·난독화는 유지). 수정 후 릴리스 APK 정상 실행.
- 확인 항목(릴리스): 온보딩 표시, 로그인, 서버 기록 복원(세월 31년·도장), 가게 상세 공식 사진 로딩, "방문 완료 · 단골 1회" 박스.
- 설치 시 디버그 앱과 서명이 달라 먼저 삭제해야 한다(`adb uninstall com.nopo.cheonnyeon`).

## 4. 안정성 (S)
- Monkey 1차 (`--throttle 100`, 5,000회 요청, seed 20261020): **4,329회**에서 중단. Monkey가 "ANR: 포커스된 창 없음"을 보고. 앱 스레드 정지가 아니라, 화면 가장자리 제스처로 앱이 홈 뒤로 가서 포커스를 잃은 상황(앱 코드 크래시·예외 없음).
- Monkey 2차 (터치·모션만, seed 77): **3,647회**에서 중단. 원인은 홈 화면(런처) 검색으로 다른 앱(은행 앱 소개 화면)이 열려 그 앱이 스스로 종료된 것. **우리 앱 크래시 아님.**
- 주의: 두 번째 실행에서 Monkey가 앱 밖(런처)에 터치를 보내 다른 앱이 열렸다. **개인 폰에서는 Monkey를 다시 돌리지 말 것.** 전용 기기나 에뮬레이터(이 PC는 메모리 부족으로 실행 불가)에서 재실행 필요 → **수동/보류**.
- 단위 시나리오: 회전·화면 복귀 시 인증 단계·시도 횟수는 `SavedStateHandle`로 유지(코드). 실기기 회전·백그라운드·권한 철회는 **수동**.

## 5. 사용자가 직접 해야 하는 시험 (최종 시연 전)

4. **릴리스 APK 전 기능 점검** — 설치·로그인·지도·상세·패스포트까지는 확인함(1-2장). 영수증·사진 인증·리뷰 작성은 릴리스에서 한 번씩 더 확인.
