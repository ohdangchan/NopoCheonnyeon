# 노포천년 APK 설치 안내 (테스트 참가자·심사용)

> S-1006 산출물. Google Play 등록 전 **직접 설치(사이드로딩)** 방법이다. 앱 화면이 아니라 배포 안내문이다.
> 요구 사양: **Android 8.0(API 26) 이상**, 인터넷(로그인·리뷰·사진), 위치·카메라가 있는 기기. 릴리스 APK는 **arm64 기기 전용**(대부분의 최근 폰). 약 48MB.

## ★ v0.3 최종 반영 (2026-10-23 밤) — 설치 안내 갱신
- 평가용 설치 파일은 릴리스 빌드(R8) APK(약 100MB). 안드로이드 8.0 이상.
- **새 폰에서는 처음이라 직접 로그인**(이메일 가입 또는 기존 계정)해야 한다. 구글 로그인은 Firebase 설정 전이라 "설정 중" 안내가 뜰 수 있다.
- 같은 폰의 디버그 빌드와 릴리스 빌드는 서명이 달라 덮어 설치되지 않는다(삭제 후 설치).
- 권한은 처음 실행 때 안내 후 요청한다(위치·카메라·알림, 사진 앨범은 리뷰 사진용).

## 1. 파일 받기
- 파일: `app-release.apk` (사용자 서명 키로 서명됨).
- 배포 담당 확인: 서명 인증서 지문은 `apksigner verify --print-certs app-release.apk`로 확인해 **배포 문서에 실제 값**을 적는다(시안의 예시 지문은 가짜이므로 쓰지 않는다).

## 2. 폰에서 설치 (파일로 받은 경우)
1. 구글 드라이브·메신저·USB로 APK를 폰에 옮긴다.
2. 파일 앱에서 APK를 연다. "이 출처의 앱 설치" 허용 화면이 나오면 **허용**(설정 > 보안/앱 > 특별한 앱 접근 > 알 수 없는 앱 설치에서 해당 앱(파일/Chrome)을 허용).
3. "Play 프로텍트 … 검사" 경고가 뜨면 **세부정보 → 무시하고 설치**(공식 스토어 등록 전 직접 서명한 앱에서 나오는 표준 경고).
4. 설치 후 열기.

## 3. PC에서 USB로 설치 (개발자·시연 준비)
```
adb devices
adb uninstall com.nopo.cheonnyeon        # 이전에 디버그 앱이 있었다면 (서명이 달라 덮어쓰기 불가)
adb install -r app\build\outputs\apk\release\app-release.apk
```
- 폰: 개발자 옵션 > USB 디버깅 켜기, 연결 시 "허용". adb 경로 `%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe`.
- 업데이트는 **같은 서명 키 + 더 큰 `versionCode`**(현재 1, `app/build.gradle.kts`)여야 덮어쓰기가 된다. 키가 다르면 삭제 후 재설치(로그인하면 서버 기록으로 복원됨, 인증샷은 기기에만 있어 사라짐).

## 4. 첫 실행
1. 온보딩 3장(건너뛰기 가능) → 회원가입(이메일, 비밀번호 영문+숫자 8자 이상, 닉네임 2~12자 한글·영문·숫자) → 지도.
2. 권한은 필요한 순간에 요청한다:
   - **위치**: 지도 "내 위치"와 **가게 사진 인증**에서. 사진 인증은 **정확한 위치**가 필요하다(대략적 위치만 허용하면 안내가 나온다). 영수증 인증은 위치가 필요 없다. 기기 위치(GPS)도 켜 둘 것.
   - **카메라**: 영수증·간판 촬영에서(앱 안 카메라만 사용, 갤러리 선택 없음).
3. 인터넷이 없어도 노포 목록·내 패스포트는 볼 수 있고, 인증은 "확인 중" 도장으로 저장됐다가 연결되면 서버에 올라간다.

## 5. 시험 계정·데이터
- 시험 계정은 앱에서 직접 가입. 끝나면 설정 > 회원 탈퇴로 삭제(비밀번호 입력).
- 테스트용 가게: 설정 > 앱 정보를 5번 누르면 나오는 "개발자 도구"에서 현재 위치에 만들 수 있다(서버에 올라가지 않음).

## 6. 문제 해결
| 증상 | 조치 |
|---|---|
| "앱이 설치되지 않음" | 같은 패키지의 다른 서명 앱이 있음 → 삭제 후 재설치. 저장 공간·Android 8.0 이상 확인 |
| 파일이 열리지 않음 | 파일 앱/브라우저의 "알 수 없는 앱 설치" 허용 |
| `NO_CERTIFICATES` | 서명 없는 APK. `keystore.properties`가 없으면 빌드가 디버그 키로 서명하도록 되어 있음 — 빌드 환경 점검 |
| 지도가 비어 있음 | 인터넷 확인. 상단에 오류 코드가 나오면 네이버 콘솔의 패키지명(`com.nopo.cheonnyeon`)·Dynamic Map 선택 확인 (401=패키지명, 429=Dynamic Map 미선택, 800=키 미지정) |
| "위치를 찾지 못했어요" | 기기 위치 켜기, 정확한 위치 허용, 하늘이 보이는 곳 |
| 영수증이 인식되지 않음 | 밝게, 평평하게, 가게명·전화·날짜가 한 화면에. 실패하면 "가게 사진으로 인증" |
| 사진이 안 뜸 | 인터넷 확인. 사진 없는 가게는 글자 카드가 정상 |
| 로그인이 안 됨 | 이메일·비밀번호, 인터넷 확인 |
