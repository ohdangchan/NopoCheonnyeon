# 노포 패스포트 v2 변경 요약 (시안 우선)

작성: 2026-10-23 · 브랜치 `redesign/v1` · 기준: `design/redesign/1~6.webp` (가장 높은 기준)
원본 문서(`docs/nopo-*.md` 등)는 수정하지 않았고, 같은 내용을 `docs/v2/v2-*.md` 로 복사해 두었다. **원본과 다르면 v2 가 우선**이다.

## 1. 원칙
- UI는 시안을 그대로 복제한다. 정적인 장식(제목 글자, 우표, 여권 그림, 하단 탭 줄)은 시안에서 잘라 쓰고(`tools/crop_mockups.py` → `res/drawable-nodpi/mk_*.webp`), 가게 이름·사진·평점·거리처럼 바뀌는 부분은 앱이 그린다.
- 좌표는 "시안 픽셀(폭 760)" 기준이며 화면 폭에 비례해 dp 로 바꾼다 (`core/designsystem/mock/MockKit.kt`).
- 시안과 PRD 가 부딪히면 시안을 따른다. 아래 표가 그 결정이다.

## 3. 화면별 결정
1. **홈**: "오늘의 AI 추천"(실패 시 가까운 평점 높은 노포로 대체), "내 주변 노포 찾기" → 탐색 탭, 하단 배너 "노포 AI 투어 코스" → AI 도우미. 카드의 거리는 현재 위치 기준 km.
2. **탐색**: 시안과 동일, 검색창 오른쪽 필터 아이콘만 AI 아이콘(AI 도우미 열기).
3. **지도**: 실제 네이버 지도 유지. 내 위치 버튼만 시안 모양, 종이비행기(방향) 버튼 삭제. 가까운 가게는 사진 말풍선 마커, 아래 "지금 이 근처 노포" 카드 목록, 시·군·구 칩.
4. **컬렉션**: 펼친 여권을 밀어서 한 장씩 넘긴다(첫 펼침=지역 스탬프 6칸+숫자, 이후=방문 도장 9칸씩). "다음 스탬프까지" → **"다음 칭호까지"**, 선물 카드 자리는 **AI 룰렛**. "수집한 스탬프" → **"수집한 칭호"**. 전체 보기에서 칭호 도감·명예의 전당·내 리뷰·공유 카드에 접근.
5. **가게 상세**: 사진은 가게의 실제 사진(가로로 넘김), "방문 인증 N명" 대신 **현재 위치와의 거리(km)**, 대표 메뉴는 `menuItems`(1,277곳 중 1,002곳 보유) 이름 + 이 가게 사진 돌려쓰기(가격은 자료가 없어 표시하지 않음), 주소 탭 → 네이버 지도 길찾기, 전화 탭 → 전화 앱. 리뷰·번역·정보 제보는 아래에 그대로 이어 붙인다.
6. **마이**: 프로필 사진(이 기기에만 저장)·닉네임 편집, 나의 노포 여정(**수집한 칭호**), 저장한 노포, **방문 기록 → 컬렉션 탭**, 알림 설정, 앱 환경 설정, 계정 관리(기존 설정 화면), 고객센터(문의 메일 안내), 최근 방문한 노포.
- **알림(종 아이콘)**: 서버 푸시 없이 기기의 방문 기록으로 "도장을 찍었어요/새 칭호" 목록을 만들고 알림 설정을 따른다.

## 4. 규칙 변경
- 도장은 **영수증 인증 → 바로 도장**(기존 방식 유지). 지역 스탬프(시·도별 5곳 방문)는 표시·진행 안내용이며 별도 보상은 없다.
- 저장하기(북마크)는 기기 안(DataStore)에만 저장하고 로그아웃·탈퇴 시 지운다.
- 평점은 시연용 예시 리뷰 평균(`DemoReviews`) 기준이다 (예시 리뷰 표시를 끄면 평점도 숨는다).

## 5. 알려진 한계 / 사용자 결정이 필요한 것
- 시안의 음식 사진은 쓸 수 없어 카탈로그 사진으로 대체했다. 대표 메뉴 사진은 메뉴별 전용 사진이 없어 같은 가게 사진을 돌려쓴다 (메뉴별 사진 확보는 출처·약관 확인 후 추가).
- 고객센터 메일 주소는 개발자 연락처(`SUPPORT_EMAIL`, `feature/my/MyScreen.kt`)를 임시로 넣었다 → **운영 주소 확인 필요**.
- 릴리스(스토어 올리기)는 마지막에 사용자가 결정한다. 현재 버전은 그대로.
- 이전 Gemini 키 폐기, App Check 재활성화, 2026-11-02 이후 AI 호출 방식은 기존 문서의 보류 항목 그대로.

## 6. 추가 반영 (2026-10-23 오후)
- 대표 메뉴 사진: 메뉴 이름으로 요리 종류를 찾아 위키미디어 공용의 자유 이용 사진(CC0/CC BY, `app/src/main/assets/menu/`, 작성자·라이선스는 `credits.json`, 받는 도구 `tools/fetch_menu_photos.py`)을 쓴다. 사진 위에 작성자·라이선스를 작게 표시한다. 맞는 사진이 없으면 가게 사진.
- 고객센터 메일은 `wow.sillyer@gmail.com` 으로 사용자가 확인함.
- 시안 글자는 시스템 글자 크기 배율과 무관한 고정 크기(레이아웃이 깨지지 않게).
- 시안이 없는 나머지 화면(로그인·온보딩·방문 인증·리뷰·프로필·명예의 전당·룰렛·챗봇·계정 관리)은 **레이아웃을 그대로 두고** 디자인 시스템(색·글꼴·버튼·카드 모서리)만 시안 스타일로 바꿨다: 크림 종이, 남색 글자, 연두 주 버튼, 제목은 나눔명조, 남색 테두리 보조 버튼.
- 시스템 다크 모드는 따르지 않고 항상 크림 종이(라이트)로 보인다.
- 시안 배율은 `MainActivity` 맨 위에서 한 번 제공하고(`ProvideMockScale`), 600dp 넘는 화면은 폭을 묶어 가운데에 둔다. 폭 308dp·360dp·432dp 폰에서 확인.
- 시스템 바는 항상 밝은 화면 기준(다크 모드여도 아이콘이 어둡게).
- 가게 상세·마이·컬렉션의 문구는 `strings_v2.xml` (일부 `${}` 포함 짧은 문구는 코드에 남음).

## 7. 시안 2차 (design/redesign2, 14장) 반영 — 2026-10-23
- 처음 설치(온보딩 3면: 첫 면은 시안 그대로, 좌우로 넘기면 앱 기능 설명), 로그인(이메일 + 구글·카카오·네이버 간편 로그인 버튼), 회원가입(약관 4항목, 간편 가입 3종), 방문 인증 전 과정(안내·촬영·정보 확인·실패 안내·위치/가게 사진·완료), AI 노포 룰렛(지역·가격대·음식 종류·도보 거리, 돌리면 사진이 돌다가 결과), 미식가 랭킹(수집한 스탬프 → 수집한 칭호), 설정(프로필 카드·7줄 메뉴·로그아웃·회원 탈퇴).
- 영수증 인증은 읽은 정보를 확인 화면에서 보여 준 뒤 "인증 정보 확정하기"를 눌러야 도장이 찍힌다 (이전: 바로 도장). 완료 화면에서 "경험치 획득" 대신 "칭호 획득".
- 룰렛은 분위기 대신 음식 종류(한식·중식·일식·양식·분식·카페). 가격대는 자료가 없어 화면 선택만 하고 AI 질문에만 반영한다.
- 하단 탭은 기존 5탭 그대로(룰렛·랭킹에도 표시).
- **간편 로그인(구글·카카오·네이버)은 각 서비스의 앱 키 등록이 필요해 지금은 "준비 중" 안내만 뜬다.** 필요한 값은 아래 요청 목록 참조.

## 8. 사용자에게 요청할 값·결정 (나중에 알려 주기로 함)
1. **구글 로그인**: Firebase 콘솔 > Authentication > 로그인 방법에서 Google 사용 설정, 앱의 SHA-1·SHA-256 지문 등록, 갱신한 `google-services.json` 파일 (파일은 저장소에 넣지 않음).
2. **카카오 로그인**: 카카오 디벨로퍼스에 앱 등록 → 네이티브 앱 키, 패키지명 `com.nopo.cheonnyeon` + 키 해시 등록, 카카오 로그인 활성화·동의 항목(닉네임, 이메일). 카카오는 Firebase 기본 제공이 아니라 서버 쪽에서 맞춤 토큰을 만드는 절차(Cloud Functions 등)가 추가로 필요.
3. **네이버 로그인**: 네이버 개발자센터에 애플리케이션 등록 → Client ID·Client Secret, 안드로이드 패키지명 등록. 카카오와 같이 맞춤 토큰 서버 절차 필요.
4. 위 2·3의 서버 절차에 쓸 Firebase 결제(Blaze) 요금제 여부 결정.
5. 휴대폰 번호 가입·친구 랭킹·서울 랭킹·메뉴 가격 자료는 데이터/서버가 없어 준비 중 표시. 필요하면 범위 결정.
6. 고객센터 문의 주소(지금은 개발자 연락처), 릴리스 시점 결정.

## 9. 시안 3차 (design/redesign2 15~21번) — 권한·GPS 인증
- 처음 실행 때 **권한 안내**(시안 19: 위치·카메라·사진 앨범·알림·신체 활동 소개)가 한 번 뜬다. "모두 허용"은 위치·카메라·알림을 시스템 창으로 요청한다. 사진 앨범·신체 활동은 앱이 쓰지 않아(갤러리 선택 금지, 걸음 수 미사용) 요청하지 않고 소개만 한다.
- 개별 안내: 카메라(시안 15, 인증 촬영 화면에서), 위치(시안 20, 지도 탭에서), 알림(시안 16, 권한 관리에서 알림을 켤 때), 꺼짐 안내(시안 17, 영구 거부 시 설정 열기).
- **권한 관리**(시안 18): 설정 → "개인정보 및 보안"이 아니라 "위치 권한 설정"/권한 관리 줄에서 연다. 위치·카메라·알림은 실제 권한 상태, 마케팅 수신·사용 데이터 수집은 앱 안 선택(기본 꺼짐, 사용 데이터 수집은 기본 켜짐, 끄면 수집 안 함), 방문 기록 공유는 공개 범위(ALL↔PRIVATE).
- **GPS 방문 인증**(시안 21): 위치 확인 → 거리(m) 표시 → "방문 인증 시작"으로 가게 사진 인증으로 넘어간다 (이전: 위치가 맞으면 자동으로 넘어감).
- 알림 권한(POST_NOTIFICATIONS)을 매니페스트에 추가했다 (안드로이드 13 이상).
