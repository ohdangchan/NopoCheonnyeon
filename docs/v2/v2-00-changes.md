# 노포 패스포트 v2 변경 요약 (시안 우선)

작성: 2026-10-23 · 브랜치 `redesign/v1` · 기준: `design/redesign/1~6.webp` (가장 높은 기준)
원본 문서(`docs/nopo-*.md` 등)는 수정하지 않았고, 같은 내용을 `docs/v2/v2-*.md` 로 복사해 두었다. **원본과 다르면 v2 가 우선**이다.

## 1. 원칙
- UI는 시안을 그대로 복제한다. 정적인 장식(제목 글자, 우표, 여권 그림, 하단 탭 줄)은 시안에서 잘라 쓰고(`tools/crop_mockups.py` → `res/drawable-nodpi/mk_*.webp`), 가게 이름·사진·평점·거리처럼 바뀌는 부분은 앱이 그린다.
- 좌표는 "시안 픽셀(폭 760)" 기준이며 화면 폭에 비례해 dp 로 바꾼다 (`core/designsystem/mock/MockKit.kt`).
- 시안과 PRD 가 부딪히면 시안을 따른다. 아래 표가 그 결정이다.

## 3. 화면별 결정
1. **홈**: "오늘의 AI 추천"(실패 시 가까운 평점 높은 노포로 대체), "내 주변 노포 찾기" → 탐색 탭, 하단 배너 "노포 AI 투어 코스" → AI 도우미. 카드의 거리는 현재 위치 기준 km.
2. **탐색**: 시안과 동일, 검색창 오른쪽 필터 아이콘만 AI 아이콘(AI 도우미 열기).
3. **지도**: 실제 네이버 지도 유지. 내 위치 버튼만 시안 모양, 종이비행기(방향) 버튼 삭제. 가까운 가게는 사진 말풍선 마커, 아래 "지금 이 근처 노포" 카드 목록, 시·군·구 칩.
4. **컬렉션**: 펼친 여권을 밀어서 한 장씩 넘긴다(첫 펼침=지역 스탬프 6칸+숫자, 이후=방문 도장 9칸씩). "다음 스탬프까지" → **"다음 칭호까지"**, 선물 카드 자리는 **AI 룰렛**. "수집한 스탬프" → **"수집한 칭호"**. 전체 보기에서 칭호 도감·명예의 전당·내 리뷰·공유 카드에 접근.
5. **가게 상세**: 사진은 가게의 실제 사진(가로로 넘김), "방문 인증 N명" 대신 **현재 위치와의 거리(km)**, 대표 메뉴는 `menuItems`(1,277곳 중 1,002곳 보유) 이름 + 이 가게 사진 돌려쓰기(가격은 자료가 없어 표시하지 않음), 주소 탭 → 네이버 지도 길찾기, 전화 탭 → 전화 앱. 리뷰·번역·정보 제보는 아래에 그대로 이어 붙인다.
6. **마이**: 프로필 사진(이 기기에만 저장)·닉네임 편집, 나의 노포 여정(**수집한 칭호**), 저장한 노포, **방문 기록 → 컬렉션 탭**, 알림 설정, 앱 환경 설정, 계정 관리(기존 설정 화면), 고객센터(문의 메일 안내), 최근 방문한 노포.
- **알림(종 아이콘)**: 서버 푸시 없이 기기의 방문 기록으로 "도장을 찍었어요/새 칭호" 목록을 만들고 알림 설정을 따른다.

## 4. 규칙 변경
- 도장은 **영수증 인증 → 바로 도장**(기존 방식 유지). 지역 스탬프(시·도별 5곳 방문)는 표시·진행 안내용이며 별도 보상은 없다.
- 저장하기(북마크)는 기기 안(DataStore)에만 저장하고 로그아웃·탈퇴 시 지운다.
- 평점은 시연용 예시 리뷰 평균(`DemoReviews`) 기준이다 (예시 리뷰 표시를 끄면 평점도 숨는다).

## 5. 알려진 한계 / 사용자 결정이 필요한 것
- 시안의 음식 사진은 쓸 수 없어 카탈로그 사진으로 대체했다. 대표 메뉴 사진은 메뉴별 전용 사진이 없어 같은 가게 사진을 돌려쓴다 (메뉴별 사진 확보는 출처·약관 확인 후 추가).
- 고객센터 메일 주소는 개발자 연락처(`SUPPORT_EMAIL`, `feature/my/MyScreen.kt`)를 임시로 넣었다 → **운영 주소 확인 필요**.
- 릴리스(스토어 올리기)는 마지막에 사용자가 결정한다. 현재 버전은 그대로.
- 이전 Gemini 키 폐기, App Check 재활성화, 2026-11-02 이후 AI 호출 방식은 기존 문서의 보류 항목 그대로.
