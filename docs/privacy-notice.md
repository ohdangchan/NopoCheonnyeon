# 개인정보·위치정보 안내 (초안)

> **초안이다.** 현재 앱의 실제 동작(코드)을 그대로 적었다. 운영자 이름·연락처·사업자 정보는 **정해진 것이 없어 비워 두었다**(`〔 〕`). `design/stitch/screens/settings/privacy_policy` 시안의 사업자번호·주소·전화·CISO·"AES-256 GCM"·"암호학적 파쇄" 같은 내용은 **가짜이거나 사실이 아니므로 옮기지 않았다.** 법적 검토 전에는 "초안"으로만 쓰고, 공개 배포 전에 변호사/기관 확인을 받는다(`nopo-05` E장).

## 1. 서비스
노포천년은 전국 백년가게·서울 오래가게를 찾아 방문을 인증하고 도장·세월을 모으는 앱이다. 운영: 〔운영자 이름〕, 문의: 〔연락처〕. 이 앱은 중소벤처기업부·서울특별시와 관련이 없다.

## 2. 서버(Firebase, 서울 리전 asia-northeast3)에 저장하는 것
| 항목 | 내용 | 비고 |
|---|---|---|
| 계정 | 이메일, (Firebase Authentication이 보관하는) 비밀번호 해시 | 앱은 비밀번호를 저장·기록하지 않음 |
| 프로필 | 닉네임, 칭호, 세월 합계, 방문 수, 리뷰 수, 가입·수정 시각 | 다른 로그인 사용자에게 공개 |
| 방문 기록 | 가게 ID·이름·지역(시군구), 얻은 세월, 도장 등급, 인증 방법(영수증/사진/위치 확인), 사진 확인 여부, 첫·마지막 방문일, 방문 횟수 | **날짜만**(서울 기준 그날 0시로 잘라 저장, 시:분 없음). 다른 로그인 사용자가 읽을 수 있음 |
| 영수증 중복 방지 | 영수증 내용으로 만든 SHA-256 해시, 사용자 ID, 가게 ID, 생성 시각 | 해시로부터 영수증 내용을 복원할 수 없음. 영수증 이미지·내용은 저장하지 않음 |
| 리뷰 | 별점, 글(선택, 500자), 닉네임, 칭호, 단골 횟수, 작성·수정 시각 | 다른 로그인 사용자에게 공개 |
| 신고 | 신고 대상 리뷰, 사유, 신고자 ID, 시각 | 운영자만 확인(앱에서는 읽을 수 없음) |
| 진단 | 개발자 진단 화면의 시험 문서(기기 모델·Android 버전) | 일반 사용자 흐름에서는 생성되지 않음 |
| 사용 통계 | Firebase Analytics(릴리스 빌드만): sign_up, login, verify_start, verify_result(오류 코드), stamp_awarded(세월·등급), review_saved, profile_open | 닉네임·이메일·위치·영수증·가게 이름은 보내지 않음 |
| 크래시 | Crashlytics 크래시 보고(릴리스 빌드만) | 앱은 이메일·위치·영수증을 보고에 넣지 않음 |

## 3. 서버에 저장하지 않는 것
- **위치 좌표**: 가게 30m 확인을 위해 인증 중 최대 15초 동안만 측정하고 기기 안에서 거리를 계산한 뒤 버린다. 서버·로그에 남기지 않는다. 백그라운드 위치는 쓰지 않는다. (지도 화면의 "내 위치" 표시도 기기 안에서만 쓴다.)
- **영수증 이미지·내용**: 앱 안 카메라로 찍어 **기기 안에서 글자 인식(ML Kit)** 한 뒤 즉시 메모리에서 지운다. 파일로 저장하지 않으며 서버로 보내지 않는다.
- **인증 시각의 시·분**.
- 실명, 주민등록번호, 전화번호(사용자 본인의), 기기 고유 식별값.

## 4. 기기에만 저장하는 것
- 가게 사진 인증 사진(인증샷): 앱 내부 저장소 `files/proofs/`, 서버로 보내지 않음. 로그아웃·탈퇴 때 삭제.
- 방문 기록 캐시(Room), 전송 대기열, 온보딩 여부·필터 설정(DataStore).

## 5. 외부 서비스로 나가는 요청
- 네이버 지도 SDK(지도 타일, 지도 인증), Google Play 서비스 위치, Firebase(Auth·Firestore·Crashlytics).
- 공식 가게 사진은 소상공인시장진흥공단 백년가게 사이트(sbiz24.kr)에서 앱이 직접 불러온다(해당 사이트에 사용자의 IP 등 접속 정보가 전달됨).
- 영수증 인증 화면은 기기 시계 확인을 위해 `https://www.google.com/generate_204`에 HEAD 요청을 보내 응답의 `Date` 헤더만 읽는다(어떤 사용자 정보도 보내지 않음, 접속 IP 등은 해당 서버에 전달됨).
- 개발자 진단 화면의 "내 위치 주소 찾기"는 좌표를 네이버 Reverse Geocoding에 보낸다(디버그 진단 용도, 저장 안 함).

## 6. 권한
위치(정밀·대략): 지도 내 위치와 가게 사진 인증. 카메라: 영수증·간판 촬영. 인터넷·네트워크 상태: 서버 통신·오프라인 표시. 진동: 도장 연출. 거부해도 지도·목록·영수증 인증(위치 불필요)은 쓸 수 있다.

## 7. 보관과 삭제
- 사용자는 설정 > 회원 탈퇴(비밀번호 재입력)로 **내 리뷰·방문 기록·프로필·닉네임 문서와 계정**을 삭제할 수 있다(기기의 방문 기록·인증샷도 삭제). 영수증 해시 문서는 규칙상 사용자가 삭제할 수 없어 남을 수 있다(영수증 내용은 포함되지 않음) — **운영 정책 결정 필요**.
- 닉네임 변경 시 옛 닉네임이 해제되고 내 리뷰의 닉네임이 갱신된다.

## 8. 위치정보 관련 확인 사항 (법무 검토 필요)
- 위치 좌표를 서버에 저장하지 않는 설계를 유지한다(저장하게 되면 위치정보법상 신고·동의 절차를 출시 전에 검토).
- 모의 위치(Mock Location)는 거부한다.

## 9. 문의·권리 행사
〔연락처〕. 열람·정정·삭제 요청은 앱의 회원 탈퇴 또는 위 연락처로.
